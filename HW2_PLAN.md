# ДЗ2 — план выполнения (Django: views, urls, templates, пагинация)

## Фаза 1 — окружение и структура проекта
1. Создать виртуальное окружение (`python -m venv venv`), активировать.
2. Установить Django внутри окружения (`pip install django`).
3. Создать проект: `django-admin startproject ask_pupkin .` (точка в конце — иначе будет лишняя вложенная папка).
4. Создать приложение: `python manage.py startapp app`.
5. Зарегистрировать `app` в `INSTALLED_APPS` (`ask_pupkin/settings.py`).
6. Создать папки `templates/`, `static/`, `uploads/` (`static/` уже частично есть — переиспользовать).
7. В `settings.py` указать пути к шаблонам (`TEMPLATES` → `DIRS`) и статике (`STATICFILES_DIRS`).
8. Обновить `.gitignore` (`venv/`, `__pycache__/`, `*.pyc`, `db.sqlite3`).
9. **Контрольная точка**: `python manage.py runserver` → дефолтная страница Django в браузере.

## Фаза 2 — первый рабочий маршрут (проверка связки)
10. Написать простую view-функцию `index` в `app/views.py`.
11. Создать `app/urls.py` вручную, прописать один маршрут на неё.
12. Подключить `app/urls.py` в корневом `ask_pupkin/urls.py` через `include()`.
13. Перенести `index.html` из ДЗ1 в `templates/`, отрисовать без данных.
14. **Контрольная точка**: `127.0.0.1:8000/` показывает вёрстку из ДЗ1.

## Фаза 3 — превращаем статику в настоящие Django-шаблоны
15. В `base.html` выделить `{% block content %}...{% endblock %}` вместо блока с карточками вопросов.
16. Добавить `{% load static %}`, заменить пути на bootstrap/картинки через `{% static '...' %}`.
17. `index.html` → `{% extends "base.html" %}` + `{% block content %}`.

## Фаза 4 — остальные 6 страниц
18. Для каждой из `/hot/`, `/tag/<slug>/`, `/question/<id>/`, `/login/`, `/signup/`, `/ask/`:
    view с данными-заглушками → именованный маршрут в `app/urls.py` → шаблон, наследующий `base.html`.
    Делать по одной странице, проверять в браузере перед следующей.

## Фаза 5 — подшаблон для карточки вопроса
19. Вынести HTML карточки вопроса в отдельный файл, подключать через `{% include %}` внутри `{% for question in questions %}`.

## Фаза 6 — пагинация
20. Написать `paginate(objects_list, request, per_page=10)` на основе `django.core.paginator.Paginator`,
    с обработкой `PageNotAnInteger` / `EmptyPage`.
21. Применить в списочных view (главная / hot / tag).
22. Сделать шаблон-подшаблон пагинатора (на основе вёрстки из ДЗ1), подключаемый через `{% include %}`,
    на реальных данных страницы (`page.has_next`, `page.paginator.num_pages` и т.д.).

## Фаза 7 — финальная проверка
23. Все ссылки в шаблонах — через `{% url 'имя' %}`, без хардкода.
24. Коммитить по ходу, после каждой рабочей фазы — не одним огромным коммитом в конце.
